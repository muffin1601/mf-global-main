# Website inventory

The public application contains a marketing home page assembled from Hero, Services, Process, Popular Categories, Raise the Bar, Why Choose Us, Testimonials, Contact, Navbar and Footer components; a contact page; blog list/detail/create/comment flows; and public careers plus a separate careers administration experience.

The migration preserves `/`, `/contact`, `/blogs`, and `/careers`. Implemented public pages use server rendering, Metadata API, canonical sitemap generation, accessible headings, and responsive navigation. Pending parity work includes migrating exact approved copy/media, blog comments/admin publishing, career applications/resume upload, the careers admin workflow, contact email delivery, structured organization/job-posting data, legacy-ID redirects, and visitor tracking.
